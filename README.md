# Portfolio — Miguel Enrique Zambrano Contreras

Portfolio personal, estático y sin dependencias, alojado en GitHub Pages.

Web: https://MikeChamp4.github.io/

## Sobre el proyecto

Un único `index.html` (HTML, CSS y JS, sin frameworks) que obtiene los datos en directo desde la API de GitHub:

- Nombre, descripción y avatar desde el perfil de GitHub.
- Proyectos: repositorios públicos marcados con el topic `portfolio`.
- Descripción y lenguajes de cada proyecto, desde cada repositorio.
- Imagen de cada tarjeta: `preview.gif` del repo si existe, o la social preview de GitHub.

Incluye tema claro/oscuro e interfaz en catalán, castellano e inglés.

## Añadir un proyecto

1. En el repositorio, sección About, añadir el topic `portfolio`.
2. Escribir una descripción.
3. Opcionalmente, subir un `preview.gif` a la raíz del repo.
